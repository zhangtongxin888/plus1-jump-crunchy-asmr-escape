# +1 Jump Crunchy ASMR Escape Beginner Guide

The long-term source for `plus1jumpcrunchyasmrescape.wiki`.

This is an independent, source-checked beginner guide for the Roblox experience made by Sky High Sims. The production site is hosted on Vercel. The Sites project recorded in `.openai/hosting.json` is a design workspace only and is not the production host.

## Local development

Requires Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

## Validation

```bash
npm run lint
npm test
```

`npm test` performs a production Next.js build and then checks the required guide content, verified identifiers, SEO files, canonical-domain redirect, social assets, and accessibility hooks.
